# 叙事链（narrative-chain）

> Append-only。每条记录 = 一次设计 run 的"纪录片"：做了什么决策、为什么、搁置了什么。
> **分层**：全局链 `_MAIN.md`（框架/读书/跨项目）+ 项目链 `<项目目录>/narrative-chain.md`（项目私有决策史）；本文件 = **全局链**。
> **读取规则**：进入设计 task 时读**当前作用域**最近 3 条（项目 run = 项目链 + 全局链；框架/读书/跨项目 = 全局链）+ 按主题检索（默认只扫活跃区）。
> **出发自**：每条可带 `出发自：<日期+标题>`（可空 = 全新主题起点）；推翻旧决策时指向被推翻条目（对方标注 ⏳已取代）；归档判定依据 = 是否仍被活跃条目出发引用。
> **归档**：主题终了（项目结项/主题段读完/模块定格）+ 无活跃引用 → 回写时提议「归档候选」→ 用户确认 → 移入 `archive/`（按主题段一文件，头部注记归档日期/理由/指向上游结论；可溯源、不占来路、不参与注入与默认检索）。
> 原始证据在对应 run 的检查点存档里，此处只存"来路"。
> 格式：

```
## [日期] 任务名（域标签 / 品类 / 流水线）
- 出发自：<日期+标题，可空 = 全新主题起点>
- 做了什么：一句话
- 关键决策与理由：2-4 条
- 搁置/遗留：当时没做、为什么
- 长出的东西：新判据/新原子/骨架修改（附路径）
```

域标签：`[framework]` 框架/插件/流程演化｜`[reading]` 读书轮｜`[project:<slug>]` 游戏项目。
