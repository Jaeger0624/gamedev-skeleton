# 来源注册表（sources）

> 外部输入沉淀（knowledge-sinking）的来源留痕**第一层**：一源一条，一源多次沉淀可追溯。
> 本目录只做**来源注册**（元数据 + 指向）；"该来源沉淀了哪些条目"的权威清单 = `skeleton/_INDEX.md` + `verdicts/_FORMAT.md` 索引表 + 书级 `book.json` yield（机器层），脚本扫描校验用 `gen-library-list`——**本文件不抄清单**（手抄=漂移）。
> 每次沉淀的 `knowledge-sinking` run 存档（00-输入快照）是**第二层**证据。
> 本表为**空包模板**：来源条目由使用者在外部输入沉淀中登记；格式：

## [slug]
