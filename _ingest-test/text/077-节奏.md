# 节奏

这个故事的节奏起伏有些不同寻常。战斗中的紧张气氛会随着长时间的对话、探索、治疗，以及打扫战场而回落。这种交替的节奏使得玩家能够保持对游戏的参与度，同时也不至于精疲力尽。

你也许会说，如果游戏节奏随着故事的进程而愈演愈烈，效果肯定会更加出彩。比如，随着任务的逐渐深入，接踵而至的战斗越发令人紧张，然后在结局时刻把整个剧情推向最高潮。这种做法看起来固然很好，然而为了达成这样的目标，我们必须解决一种有可能会出现情况：玩家可以在任意时刻暂时放弃或者重新继续完成任务。在这种情况下，我们精心打造的游戏节奏就会被粗心大意的玩家所破坏。考虑到这种不可预料的情况，让游戏保持频率稳定的波动可能是最好的解决方案，因为当游戏节奏被破坏和重组时，这种方式受到的影响会比较小。
