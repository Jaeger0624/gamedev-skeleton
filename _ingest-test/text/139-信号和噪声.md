# 信号和噪声

玩家得到的每一种信息都是某个信号的一部分。信号会通过多种不同的渠道传递，比如屏幕中的画面，扬声器发出的声音，可能还有触觉或者其他一些信息的反馈。玩家通过人类与生俱来的能力对这些信息进行过滤、排序，以及解释，试图理解信号所传递的意思。但是如果这个过程失败了，一部分信号就会变成噪声。

噪声是指未能传递有意义信息的一种信号。

噪声并非仅限于像电话杂音那样无意义的信号，还指游戏中所有无法向玩家的内心传递有意义信息的信号。无论这些信号是被审美因素所影响，还是必须使用超高的技巧才能解读，或者是和其他信号的联系过于紧密，结果都一样：玩家不理解游戏中的事件，因此没有考虑或者响应它。

噪声主要有两种成因：复杂的美术效果和过多的信号。
