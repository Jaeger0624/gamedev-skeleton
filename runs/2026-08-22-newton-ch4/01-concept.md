# 阶段 1：概念定位（线 A + 线 B）

> 注入原子：skills/perspective-shift（视角置换：从玩家"没想到"的洞见出发）+ analogy（类比已有解谜经典结构）

## 线 A：第 4 章 Portal/Time

### 视角置换：玩家在前三章学会了什么？

- Ch1 学会：**空间是直的**——重力向下，弹板反射方向可预测
- Ch2 学会：**路径是有序的**——节点有编号，顺序即约束
- Ch3 学会：**空间可以被场域扭曲**——引力/斥力/重力翻转改变了"直"的定义

**玩家的心智模型**：空间是连续的、因果是即时的、路径是唯一的。

**第 4 章要打破的**：空间可以不连续（传送门）、因果可以延迟（回溯）——这是从前三章"扭曲空间"到"改写空间结构"的质变。

### 类比映射

- 传送门在解谜史上的地位：Portal（Valve）证明了"空间折叠"是解谜的最高级形式之一——它不要求玩家学会新操作，而是**颠覆对空间的基本假设**
- 回溯在 Braid 中的地位：时间倒流不是"撤销"，而是**让过去成为解谜资源**
- 两者的共性：**不改变规则，改变规则的拓扑结构**——空间还是那个空间，但连接方式变了；时间还是那条河，但你可以回到上游

### 概念定位

**章节名**：`时缝之间`（Between the Seams）

**核心幻想**：牛顿的经典物理学在这里失效——不是被推翻，而是被**绕过**。空间可以折叠，时间可以打结，花生从"不可能"的路径抵达。

**机制引入节奏**：
- 传送门（Ch4 前半）：先单门（空间折叠直觉），再双门（方向控制），再与已有装置组合（弹板+门=折叠弹道，场域+门=跨空间力场）
- 回溯（Ch4 后半）：先单次回溯（时间锚点），再与多次节点组合（时间换次数），再与时序门组合（时间窗口）

**情绪曲线**：
```
震撼（空间居然可以折叠？）
→ 兴奋（我可以用门做以前做不到的事）
→ 困惑（回溯让事情变得复杂了）
→ 顿悟（原来回溯不是撤销，是资源）
→ 掌控（我可以同时操纵空间和时间）
```

## 线 B：从零设计新章节主题

### 视角置换：已有章节覆盖了哪些"物理直觉"？

- Ch1：经典力学（重力、弹性碰撞）
- Ch2：路径规划（顺序、重复）
- Ch3：场论（引力、斥力、重力方向）

**尚未触及的物理直觉**：**参照系**——如果"下"不是固定的呢？如果玩家可以旋转整个世界？

### 概念定位

**章节名**：`相对性`（Relativity）

**核心幻想**：爱因斯坦狭路相逢——不是装置在帮花生，而是**整个世界的方向**在帮花生。

**新机制**：**重力方向旋转**——玩家可以在布置阶段旋转整个关卡的重力方向（0°/90°/180°/270° 四档），装置和节点不动，但"下"的定义变了。

**为什么是独特的**：
- 与 Ch3 反重力区域的区别：反重力是局部翻转，相对性是全局旋转——前者是"区域内重力向上"，后者是"整个世界的下变成了左"
- 与已有所有章节的关系：它不是新增装置，而是**改写已有装置的语境**——同一块弹板，在 0° 和 90° 重力下功能完全不同
- 与主题的契合：牛顿 vs 爱因斯坦的终极对决——经典力学的绝对时空 vs 相对论的参照系依赖

**机制引入节奏**：
- 先 180°（上下颠倒，最直觉的旋转）
- 再 90°/270°（侧向重力，弹板变成"地板"）
- 再 45°（斜向重力，轨迹变成抛物线族）
- 最后与传送门/回溯组合（旋转+折叠=真正的时空操纵）

**情绪曲线**：
```
违和（这个世界怎么歪了？）
→ 适应（原来弹板在这个方向下是这样用的）
→ 惊喜（同一个布局，转个方向就通了）
→ 顿悟（没有"正确"的方向，只有"合适"的方向）
→ 敬畏（我不仅在布置装置，我在布置物理定律）
```

**发掘潜力**：这个机制天然支持"一关多解"——同一关卡在不同重力方向下可能有完全不同的解法，甚至某些解法只在特定方向下成立。
