# 阶段 0：事实档案 —— 储君（The Regent / 儲君）

> 来源：stratgg.com 全 88 卡池、sts2.untapped.gg、IGN wiki、4gamers 攻略、dualshockers、sts2front、vgover 官方特报（2026-02 至 2026-08 检索）。
> 检查点：以下每条事实可溯源。

## 角色身份与基调

- 「群星王座的继承人」，傲慢的外星储君，从不自己走路，由小橙仆从抬着巨大王座移动
- 设计幻想：**「让别人替我干活」**——辉星、仆从、铸剑，全是"储君不动手"的表达
- 起始：75 HP；遗物「天赋君权」（Divine Right）：每场战斗开始获得 3 辉星
- 解锁：先打静默猎手；储君通关后解锁亡灵缚师

## 机制骨架（4 根支柱）

### 支柱 1：辉星（Stars）— 跨回合第二资源
- 跨回合保留、无上限、不自动再生
- 卡牌同时消耗能量+辉星；生成端与消耗端必须平衡（前期 3 基础 + Venerate 每循环仅 +2，第二张星卡可能打不出——张力来源）
- 关键生成卡：Venerate(起始)、Gather Light、Hidden Cache(延迟回合)、Genesis、封印王座(Boss遗物级)、辉光(1费=2星+抽2)
- 关键消耗卡：Astral Pulse(0费3星 AOE 14)、Gamma Blast(0费3星 13伤+虚弱易伤)、七星、星灭(耗全部星×3 AOE)
- 双轨循环核心：**辉光 + 星位序列+**（0费耗2星回3能量）= 原生永动机潜力

### 支柱 2：铸造（Forge）与君王之剑（Sovereign Blade）
- 每场战斗首次打出铸造词条 → 生成无色卡「君王之剑」（2费 打10，**保留**）
- 此后每次铸造为其叠伤害（本场战斗内）
- 关键卡：淬鍊刀刃(1费,Forge 6,下回合回1能)、熔炉(每回合 Forge 4)、鑄劍者(1费4星 Forge 40)、征服者(本回合剑伤×2)、徵召上前(Summon Forth, 剑回手)、追蹤之刃
- 约束：剑不能火堆升级（战斗外不存在），可 Apotheosis；铸剑流卡组须 <20 张

### 支柱 3：仆从转化（Minion Transform）
- 将手牌/抽牌堆的牌转化为 0 费仆从token：BEGONE!(手牌1张→仆从打击)、CHARGE!!(抽牌堆2张→仆从打击)、GUARDS!!!(手牌任意张→仆从牺牲,0费11格挡消耗)
- 价值三重：强制过牌 / 烧掉废牌压缩卡组 / 0费伤害补充
- 与 Debris 系（Collision Course/Crash Landing 产废墟）协同：废牌变原料

### 支柱 4：无色协同（Colorless Synergy）
- 君王之剑本身是无色卡；Spectrum Shift(每回合开始+1随机无色卡)、Manifest Authority(7甲+1随机无色)、Largesse(合作模式给队友无色)
-  payoff：Supermassive(1费 5伤 + 本局每创造1卡+3)、Pillar of Creation(创造物→大量格挡)

## 已有流派地图（社区共识）

| 流派 | 核心 | 状态 |
|---|---|---|
| 辉星爆发/资源流 | 辉光+星位序列循环，星辰大牌收割 | S/A，主流，共识最厚 |
| 铸剑养成流 | 铸造叠剑，征服者爆发 | A，主流，需 <20 卡 |
| 手牌/抽牌控制流 | Cosmic Indifference + Glimmer 置顶循环，Kingly Punch/Kick 成长 | 有雏形，攻略提及但体系薄 |
| 仆从献祭流 | GUARDS!!! + 献祭爆发 | **B 级，日区社区发现，EN/CN 数据稀缺，明确标注"最冷门"** |
| 无色创造流 | Spectrum Shift + Supermassive | 被描述为"引擎而非卡组"、"像买彩票"，无成形构筑 |

## 社区共识的硬规则

1. **Never mix Stars and Forge**——Act 1 结束前必须站队，50/50 混搭稳定输专精
2. 星辰流可到 25 卡（Big Bang 0费万能引擎托底）；铸剑流须 <20 卡
3. A8 是难度断崖；Mini Regent 遗物（耗星→力量）是高进阶救命阀
4. 大爆炸(Big Bang)是全流派无条件第一抓位
5. 通用卡三杰：大爆炸、何人僭越(Know Thy Place)、护驾

## 空白地带（设计机会）

1. **仆从流是明文标注的 B 级洼地**——有主题（仆人抬王座、随用随抛）、有token、有 GUARDS!!!，但没有专属 payoff 卡和成型流派
2. **无色协同有引擎无构筑**——Supermassive/Spectrum Shift 是零件不是流派
3. **手牌控制流缺专用引擎**——Cosmic Indifference/Glimmer 是通用好卡，但没有围绕"置顶/回手"的流派级核心
4. **主题错位**：仆人抬王座的主题浓度 vs 仆人机制的边缘化不匹配——flavor 与 mechanics 未对齐
5. **多人合作**：Largesse 是唯一合作卡，储君的"君主"幻想在合作模式几乎空白

## 本次设计目标

为储君设计一系列补强内容，主攻空白地带 1（仆从流成型）+ 2（无色构筑化），兼及 5（合作），且必须遵守社区硬规则 1（不破坏星辰/铸剑的专精结构）。
